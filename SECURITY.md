# Security Policy

## Reporting a Vulnerability

Do not open a public GitHub issue for security problems.

Email **smmartbiz@gmail.com** with:

- a description of the issue
- steps to reproduce
- impact assessment if known

You will receive a response as soon as possible. Please do not disclose the issue until a fix is released.

## Secrets

Never commit Google service-account keys, MCP bearer tokens, or `.env` files.
